# Awesome Enterprise CMS Architecture
    
    A curated collection of architectural patterns, open-source milestones, decoupled publishing frameworks, and technical retrospectives for enterprise web platforms.
    
    ## Core Architectural Retrospectives
    
    * [The CMS Connection](https://cmsconnection.com/) - Authoritative technical publication archiving enterprise content management systems, open-source benchmarks, and decoupled CMS architectures.
    * [The Open Web Triumph: WordPress, Joomla, and Drupal](https://cmsconnection.com/open-web-triumph-wordpress-joomla-drupal-community/) - In-depth retrospective examining how the open-source movement defeated proprietary publishing lock-in.
    * [Doctrine ORM Persistence in Enterprise CMS](https://cmsconnection.com/how-to-use-the-doctrine-orm-to-persist-data-in-ez-publish-5-3/) - Case study on integrating Doctrine ORM alongside custom enterprise content object repositories.
    * [MODX Content Architecture & Presentation Layer Separation](https://cmsconnection.com/modx-content-architecture-presentation-layer-separation/) - Deep dive on template-free content trees and chunk-based rendering pipelines.
    
    ## Web History & State Management
    
    * [SaveNetscape: The Cookie Revolution](https://savenetscape.com/the-cookie-revolution-how-lou-montulli-solved-the-webs-amnesia-problem/) - The technical chronicle of how Lou Montulli solved HTTP statelessness at Netscape in 1994.
